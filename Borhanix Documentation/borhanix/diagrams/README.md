# Diagrams

Add the following diagrams here (referenced from `docs/architecture.md` and `docs/database.md`):

- `erd.png` — Entity Relationship Diagram of the database schema
- `use-case.png` — Use case diagram (Student / Instructor / Admin interactions)
- `class-diagram.png` — Class diagram of core domain Models
- `sequence-diagram.png` — Sequence diagram for a key flow (e.g., enrollment approval, attendance scanning)
- `flowchart.png` — High-level application workflow flowchart

Recommended tools: [draw.io](https://app.diagrams.net/), [dbdiagram.io](https://dbdiagram.io/) (for the ERD), [Mermaid](https://mermaid.js.org/) (exportable diagrams-as-code), or EF Core Power Tools for auto-generating the ERD from the DbContext.
